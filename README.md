# Welding Job Calculator

This is a simple Python program that calculates the estimated time needed to complete a welding job.

## What It Does

The program asks the user for:

- The number of welds required
- The estimated minutes per weld

It then calculates the total welding time.

A time conversion feature was also added that converts the total minutes into hours and remaining minutes.
